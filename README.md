# Tulsi Almirah

A responsive storefront for Tulsi Almirah in Hind, Uttar Pradesh. Browse twelve steel almirahs, compare photos and contact the shop about a model.

## Project timeline

Project start: May 2025. This Git history was reconstructed in November 2026. The May–June 2025 commit dates were assigned retrospectively to represent a sample development schedule. They do not record when the source or the photographs were originally created. The product photos and brand artwork come from Tulsi Almirah’s September 2025 catalogue.

## Run locally

From the repository root, start a static file server:

    python -m http.server 8000

Open http://localhost:8000. The site uses HTML, CSS and JavaScript with no build step.
